# 简历-岗位智能匹配系统 — 操作手册

## 一、环境启动（每次开机后执行）

```bash
# 1. 启动 Hadoop（HDFS + YARN）
start-dfs.sh
start-yarn.sh

# 2. 验证进程（应看到 NameNode / DataNode / ResourceManager / NodeManager）
jps

# 3. 进入项目并激活 Python 环境
cd ~/workflow
source ~/ai_env/bin/activate
```

## 三、启动 Streamlit 展示页面

### 基础版（无 AI 分析）

```bash
cd ~/workflow && source ~/ai_env/bin/activate
streamlit run workflow/12_streamlit_web/app.py --server.port 8501
```

浏览器打开 `http://localhost:8501` 或 `http://你的IP:8501`

### AI 增强版（需先装 Ollama）

```bash
# 安装 Ollama（仅首次）
sudo apt install curl -y
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:7b

# 启动 Ollama 后台 + Streamlit
ollama serve &
sleep 2

cd ~/workflow && source ~/ai_env/bin/activate

OPENAI_BASE_URL=http://localhost:11434/v1 \
OPENAI_API_KEY=ollama \
AI_MODEL=qwen2.5:7b \
streamlit run workflow/12_streamlit_web/app.py --server.port 8501
```

## 四、HDFS 操作

### 前置条件

确保 Hadoop 已启动：

```bash
jps          # 看到 NameNode / DataNode 则正常
```

如果未启动：

```bash
start-dfs.sh
start-yarn.sh
```

### 1. 创建目录并上传数据

```bash
cd ~/workflow && source ~/ai_env/bin/activate

# 创建 HDFS 项目目录
python src/hdfs_utils.py setup

# 上传本地 CSV 到 HDFS
python src/hdfs_utils.py upload

# 查看 HDFS 上的文件
python src/hdfs_utils.py list
```

### 2. 手动 HDFS 命令

```bash
# 查看目录
hdfs dfs -ls -R /resume_matching/

# 上传单个文件
hdfs dfs -put ~/workflow/data/resumes.csv /resume_matching/raw_data/

# 下载文件到本地
hdfs dfs -get /resume_matching/cleaned_data/cleaned_resumes/part-00000-*.csv ~/downloads/

# 查看文件内容（前几行）
hdfs dfs -cat /resume_matching/raw_data/resumes.csv | head -20

# 删除文件或目录
hdfs dfs -rm -r /resume_matching/some_folder/

# 创建目录
hdfs dfs -mkdir -p /resume_matching/new_folder/
```

### 3. Web 页面下载 HDFS 文件

1. 浏览器打开 `http://你的IP:9870`
2. 点 `Utilities` → `Browse the file system`
3. 逐层进入：`/resume_matching/cleaned_data/cleaned_resumes/`
4. 点文件名（蓝色链接）即可下载

## 九、常见问题

**Q: 端口被占用**  
`streamlit run --server.port 8502` 换一个端口

**Q: HDFS 报 Connection refused**  
说明 Hadoop 没启动，执行 `start-dfs.sh`

**Q: Python 找不到模块**  
确认已运行 `source ~/ai_env/bin/activate`，确认已安装依赖 `pip install -r requirements.txt`

**Q: 内存不足**  
关闭浏览器和其他程序，YARN 和 Spark 比较吃内存

**Q: 步骤之间互报找不到文件**  
必须按 1→11 顺序执行，上一步产出下一步的输入
